# Skripty-pro-zpracovani-dat-KOH-a-SoP-DP
Skripty pro zpracování naměřených dat v diplomové práci. 
  - Složka KOH - skript pro zpracování naměřených dat koherentního systému z ADVA. Soubory jsou ve formátu .perf. Umožňuje hledání oblastí při změnách měření nebo výpočet průměrných hodnot za celé měření a směrodatných odchylek
  - Složka SoP - skript pro zpracování naměřených dat SoP z polarimetru. Soubory jsou ve formátu .hdf5. Umožňuje hledání oblastí při změnách měření, nebo výpočet průměrných hodnot za celé měření a směrodatných odchylek
  - Složka EXFO - obsahuje skripty pro zpracování naměřených dat z EXFO FTB-1. První skript parceling1.py slouží pro převod dat do excel souboru a druhý skript cisteni_upr.py slouží pro následnou úpravu a zpracování převedených dat
